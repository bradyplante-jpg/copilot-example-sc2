You must extract all files from the zip file
Run the software before the game
It doesn't have a UI
It must run with 64 bit sc2
If there is an error while running the game, please try again
The software will exit when the game exits
If it says it didnt find a VRUNTIMEXXX_X.dll, install this. https://download.visualstudio.microsoft.com/download/pr/32627d38-bc92-4f7c-b4e2-72595c3d6dbc/BC34373DB78FD734657BFA7BD1E612C8B1B46DD467967F33E0044CA66FFA1892/VC_redist.x64.exe

After using it for a while, if any keys do not work (only can see the enemies with fog), please restore config.ini through config_bak.ini

Tiehack key: F12
Observer panel key: . 
Zoom out/in key: + -
Zoom reset key: *
They are all on the numpad.

If you don't have a numpad, you can use ShowKeyCode.exe to get the keycodes and modify they in config.ini, and it will take effect immediately without restarting

If only obs panel doesn't work, uncheck 'Disable Windows Key' (Menu > Options > Mouse and Keyboard)

(It is to avoid hotkey conflicts) Unbind your hotkeys before using obs-panel(production panel): Menu > Options > Hotkeys > Global > Observer


If the game get updated, please wait a while and download the latest one
